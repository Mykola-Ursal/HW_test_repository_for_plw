# Вимога: пошук інструкцій для автомобіля

## Початковий стан

- Користувач відкрив QAuto та увійшов через `Guest log in`.
- Після входу доступне ліве меню з пунктом `Instructions`.

## Сценарій

1. Перейти до розділу `Instructions`.
2. У полі Brand обрати `BMW`.
3. У полі Model обрати `X5`.
4. Натиснути `Search`.

## Очікуваний результат

- Відображається щонайменше одна картка інструкції.
- Назва кожної показаної картки стосується `BMW X5`.
- У кожній картці доступне посилання або кнопка `Download`.

## Межі

- Model залежить від Brand.
- Перевіряється пошук і відображення результатів, а не завантаження PDF.
- Точні HTML-атрибути й CSS-класи не задані.
- Ознаки елементів треба підтвердити за поточним UI.
- Якщо для `BMW X5` немає результатів або UI відрізняється від вимоги, треба
  зафіксувати blocker, а не вигадувати успішний результат.

## Візуальний приклад

`requirements/instructions-search.png` показує структуру сторінки на прикладі іншої
пари Brand/Model. Скріншот не задає test data для автоматизованого сценарію.
